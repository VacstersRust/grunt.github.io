# ГРУНТ / ИСТРА — Release v4 (29.10.2026)

Готовый многостраничный статический сайт: HTML, CSS, JavaScript. Работает без сборки, базы данных и платных сервисов.

## Быстрый запуск

- Откройте `index.html` локально или запустите `python -m http.server 8080` в этой папке.
- Для GitHub Pages: загрузите **содержимое** папки в корень репозитория, затем Settings → Pages → Deploy from a branch → main / root.
- Домен и HTTPS настраиваются у хостинга; не прописывайте произвольный адрес в `canonical` или OG-тегах.

## Изменения v4

- Быстрый выбор направления на главной с переходом к предварительно заполненной заявке (GET-параметры, без сервера приёма заявок).
- Более короткая заявка: обязательны только тип задачи и населённый пункт; нет требования указывать свои контакты до передачи текста.
- Памятка из четырёх пунктов перед выездом, отдельные пояснения «что сообщить / что не входит автоматически» на всех 8 страницах услуг.
- JSON-LD с описанием организации/услуги без неподтверждённых адресов, цен и отзывов.
- Собственная OpenGraph-обложка `assets/img/og-cover.jpg`, подключается абсолютным URL при финализации домена.
- Подправлена доступность мобильного меню: закрытие по клику вне меню, актуальная метка кнопки.

- Главная, каталог **8 услуг**, **8 отдельных SEO-страниц услуг**, страница техники, сценарии, контакты и локальный конструктор заявки, конфиденциальность, авторство фотографий и 404. Итого 16 HTML-файлов.

## Перед фактической публикацией обязательно

1. **Подтвердите телефон**, бренд, собственника и право использования изображений. Изображения — иллюстрации услуг, не подтверждённое портфолио.
2. **Подтвердите модель, массу, габариты, оснащение, тарифы и график**. Мы не публикуем выдуманные характеристики и цены.
3. **Укажите домен и заполните SEO:** абсолютные `canonical`, `og:url`, `og:image`, `sitemap.xml` после выбора домена.
4. **Проверьте юридическую информацию**: страница конфиденциальности описывает работу текущей формы, но не заменяет персональную политику конкретного оператора.
5. **Проверьте Google Fonts**: для CSS используется внешний импорт, других сторонних изображений/скриптов нет. При необходимости удалите импорт (используются системные fallback-шрифты).
6. **Форма НЕ отправляет данные автоматически.** Для полноценного приёма заявок подключите backend, форму поставщика или подтверждённый канал связи. Пока пользователю доступны звонок и генерация текста, а также SMS на телефонах.

## Подключение домена и индексации

Когда появится реальный домен или URL GitHub Pages, запустите из корня сайта:

```bash
python tools/finalize_domain.py https://example.ru/
python tools/check_site.py
```

Первый скрипт заменяет OpenGraph на абсолютные URL, добавляет `canonical`, `og:url`, `sitemap.xml`, обновляет `robots.txt` и закрывает 404 от индексации. **Не запускайте с `example.ru` для реальной публикации** — это только пример. Для GitHub Pages в подпапке укажите полный URL включая подпапку и завершающий слеш. Если домен поменяется, запустите скрипт с новым URL повторно.

## Оговорки по изображению и заявке

Фото предоставлены владельцем для дизайна. Не используйте их как подтверждение фактически выполненных заказов без отдельного подтверждения. Быстрая форма в URL может передавать название населённого пункта в адресной строке и логах хостинга; не вводите туда полный адрес или персональные данные.
