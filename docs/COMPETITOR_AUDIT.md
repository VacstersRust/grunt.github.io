## Слабые места рынка, превращённые в UX-требования

1. **Каталог вместо задачи** → структура по работам («Траншеи», «Дренаж», «Фундаменты», «Планировка»).
2. **Часовая цена без состава работ** → никаких придуманных прайсов; прозрачное объяснение факторов стоимости.
3. **Общие обещания компактности без модели** → реальные габариты только после подтверждения; перед выездом уточнить ширину ворот.
4. **Мало подготовки к заказу** → конструктор технического сообщения, подсказки к полям.
5. **SEO-порталы с общими формулировками** → отдельные локальные URL и конкретные сценарии с перспективой реальных фото и кейсов.
6. **Нечёткое происхождение фотографий** → подписи «иллюстративно», атрибуция, замена на съёмку собственного объекта.

## Отличие концепции

> «Подберём формат земляных работ по вашей задаче и условиям участка», а не «самая дешёвая аренда экскаватора».

Важное ограничение: без информации об операторе, технике и результатах работ такое позиционирование остаётся проектным. Не следует выдавать его за уже проверенный уровень сервиса.
