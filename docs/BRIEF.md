# ГРУНТ / ИСТРА — продуктовый и дизайн-бриф

Статус: **рабочая концепция**, подготовленная 29 октября 2026 года. Название, реквизиты и характеристики техники подлежат согласованию с владельцем бизнеса. Это **не заявление**, что такая компания уже существует.

## 1. Задача проекта

Создать узнаваемый, быстрый, адаптивный статический сайт подрядчика по земляным работам **мини-экскаватором** в Истре и городском округе Истра. Сайт должен приводить пользователя от конкретной хозяйственной задачи к структурированной заявке, а не вынуждать разбираться в каталоге строительной техники.

### Ключевое позиционирование

**«Малая техника. Точная работа.»** — подрядчик для частных участков, ИЖС и локальных работ, где важны условия подъезда и детальная постановка задачи. Утверждения «собственный парк», «работаем за час», «от X ₽», точные технические параметры, гарантии и рейтинг **не используются**, пока нет фактического подтверждения.

**География:** Истра, Дедовск, Снегири, Новопетровское, Бужарово и другие адреса внутри городского округа Истра по согласованию.

**Целевая аудитория:** владельцы частных участков, строители малоэтажных объектов, небольшие бригады инженерных коммуникаций, подрядчики по дренажу.

**Боли:** неизвестно, проедет ли техника в узкий проезд; непонятно, какие размеры сообщить; риск повреждения существующих сетей; неясно, входит ли доставка и вывоз грунта; цены за час/смену не объясняют итоговый бюджет.

**Работа пользователя:** определить подходящую услугу → понять, какие вводные нужны → описать объект → сформировать техническое сообщение → передать подрядчику.

## 2. Голос бренда

Технический, спокойный, уверенный, без агрессивных рекламных обещаний и клише. Короткие заголовки и понятные пояснения. В каждой точке касания показывается, **почему нужны размеры, доступ, грунт и информация о коммуникациях**.

Примеры тональности:
- «Малая техника. Точная работа.»
- «Сначала проверим проезд — потом согласуем выезд.»
- «Не называем цену без понимания задачи.»

| Body | Manrope / Segoe UI fallback | 13–16 px |
| Display | Oswald / Arial Narrow fallback | 43–128 px |
| Сетка | 12 колонок, 14 px gutters | нестандартные блоки 7/5, 1.14/.86 |
| Контейнер | до 1440 px | адаптивные боковые поля 18–76 px |

Принципы:
1. Доминанта — реальная техника и грунт крупным планом, с наклонными диагоналями ковша, графическими координатными метками и измерительными линиями.
2. Контрастные размеры: крупная ультрасжатая типографика рядом с небольшими информативными подписью и техническими метками.
3. Ритм «темнота → изображение → техническая светлая плашка → снова темнота».
4. Строгая сетка без «плавающих» декоративных виджетов; фото — часть архитектуры композиции, не случайный фон.
5. Анимации только при скролле и наведении, учитываются `prefers-reduced-motion`.

## 5. Архитектура сайта

```text
/                           Главный лендинг
/services/                  Каталог + фильтр работ
/services/transhei.html      Траншеи
/services/drenazh.html       Дренаж
/services/fundament.html     Фундаменты и котлованы
/services/planirovka.html   Планировка участка
/equipment/                 Техника, условия подъезда
/projects/                  Сценарии работ (не портфолио)
/contacts/                  Конструктор заявки
/privacy/                   Техническое описание обработки данных
/photo-credits.html          Авторы и лицензии фотографий
/404.html                   Ошибка 404
```

Главный лендинг: hero → навигационная строка услуг → услуги → преимущества конкретного формата мини-техники → блок техники → процесс → география → сценарии → FAQ → CTA.

### Атомарный состав

**Атомы:** цветовые токены, typography, eyebrow, button, arrow, rule, icon, form field, label.

**Молекулы:** навигационная ссылка, карточка услуги, фотокарточка, строка техпараметра, FAQ, индикатор шага.

**Организмы:** header, photo hero, service grid, technical split, steps, region panel, case gallery, lead builder, footer.

**Страницы:** собираются из одних и тех же классов компонентов. Итог — статические HTML без сборщика.

## 6. SEO и конверсия

- Уникальный `title`, `description`, `h1` на каждой странице.
- Навигация с реальными ссылками и глубиной не больше двух уровней.
- Семантические `section`, `article`, заголовки, `alt` и `details` для FAQ.
- Ядро запросов: «услуги мини-экскаватора Истра», «копка траншеи Истра», «дренаж экскаватором Истра», «земляные работы Истринский округ».
- Не используем фальшивые отзывы, рейтинги, кейсы, «от» цены или срок подачи без доказательств.
- Микро-конверсия: «обсудить работу» → сбор структурированных данных.
- Финальная конверсия зависит от подключения реального адреса для заявок в `assets/js/config.js` или серверной обработки формы.

## 7. Перед запуском: факты, которые нужны от владельца

1. Реальное коммерческое название и логотип; **телефон +7 926 416-33-27 уже внесён**, способ приёма онлайн-заявок ещё не настроен.
2. Марка/модель мини-экскаватора, ширина, глубина, ковши, условия транспортировки; документы при необходимости.
3. Режим работы, условия выезда, минимальный заказ, тарифы, входит ли топливо/оператор/доставка/вывоз.
4. Свои фотографии и подтверждённые выполненные объекты (только с разрешением заказчиков).
5. Реквизиты оператора данных, юридически проверенная политика для реального формата обработки обращений.
6. Домен для канонических URL, sitemap.xml, карт и регистрационных профилей бизнеса.
